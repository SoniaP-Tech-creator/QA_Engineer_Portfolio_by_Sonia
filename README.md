What's in This Portfolio?

- Testing Projects

Practical testing exercises on applications such as SauceDemo, where I explore functionality, investigate unexpected behaviour, and document my findings.

- Test Cases

Test scenarios, preconditions, execution steps, expected results, actual results, and test outcomes.

- Bug Reports

Documented defects with clear reproduction steps, expected versus actual results, and supporting evidence where available.

- Test Plans & Strategies

Testing objectives, scope, approaches, risks, and other planning exercises as I develop my understanding of structured testing.

- Learning Notes

Notes and practical exercises based on software testing concepts, including the ISTQB Certified Tester Foundation Level (CTFL) syllabus.
